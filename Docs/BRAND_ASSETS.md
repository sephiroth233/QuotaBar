# Brand assets

QuotaBar displays provider marks only to identify the service associated with each quota card. All trademarks remain the property of their respective owners.

- `OpenAI.png`: OpenAI Blossom from the official `openai/openai-agents-python` documentation assets. It is rendered as a monochrome template image so macOS can preserve contrast in light and dark appearances.
- `OpenRouter.png`: OpenRouter glyph from `https://openrouter.ai/brand/v2/openrouter-glyph-light.svg`.
- `DeepSeek.png`: DeepSeek mark from the current official `https://www.deepseek.com/favicon.ico`.

The source proportions are preserved. Do not redraw, stretch, or add effects to these marks.
